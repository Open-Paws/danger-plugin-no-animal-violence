# danger-plugin-no-animal-violence

Danger.js plugin that flags speciesist language in PR diffs and suggests inclusive alternatives. Part of the [Open Paws](https://github.com/Open-Paws) speciesist language detection suite.

## Quick Start

```bash
# Install dependencies
npm install

# Build TypeScript to dist/
npm run build

# Use in a Dangerfile
# import noAnimalViolence from "danger-plugin-no-animal-violence";
# noAnimalViolence({ severity: "warn" });
```

## Architecture

Single-module TypeScript plugin (`src/index.ts`), compiled to CommonJS:

1. **Pattern dictionary** — array of `{ regex, phrase, alternatives[] }` objects, auto-generated from `project-compassionate-code`
2. **Diff scanner** — iterates `danger.git.modified_files` and `danger.git.created_files`, reads diffs via `danger.git.diffForFile()`, scans only added lines (`+` prefix)
3. **Reporter** — calls `warn()` or `message()` (configurable) with file path, phrase found, and suggested alternatives

Options: `{ severity: "warn" | "message" }` (default: `"warn"`)

## Key Files

| File | Description |
|------|-------------|
| `src/index.ts` | Plugin entry point — patterns, diff scanning, reporting |
| `package.json` | NPM manifest, peer dependency on `danger >=10` |
| `tsconfig.json` | TypeScript config — targets ES2018, outputs to `dist/` |
| `dist/` | Compiled output (generated by `npm run build`) |
